Primjeri iz gradiva

Kako ESPRIT projekt EU-a definira elektroničko poslovanje?
Opći koncept koji obuhvaća sve oblike poslovnih transakcija ili razmjene informacija izvedenih pomoću ICT-a — među tvrtkama, s kupcima ili s javnom upravom, uključujući e-trgovanje.
Koje tri skupine sudionika označavaju slova B, C i G?
C (Customer) = pojedinci, fizičke osobe. B (Business) = tvrtke iz privatnog sektora, pravne osobe. G (Government) = organi državne uprave i javna poduzeća.
Koja je razlika između Interneta i weba?
Internet je platforma — globalna računalna mreža bez vlasnika. Web je servis (usluga) unutar Interneta koji se najčešće koristi HTTP protokolom.
Što obilježava Web 1.0?
Mreža SAMO ZA ČITANJE — server side includes i CGI, nema korisnički generiranog sadržaja; ukinuta su geografska ograničenja dijeljenja informacija.
Navedi nekoliko od 10 digitalnih trendova u hotelijerstvu.
Tehnologija prepoznavanja, roboti, mobilna integracija i beacon, chatbotovi i AI, personalizacija, IoT, VR i AR, glasovno rezerviranje, beskontaktno plaćanje te veliki podaci.
Što je turistički distribucijski sustav?
Sustav koji objašnjava kako turistički proizvod dolazi do kupca — povezuje primarne dobavljače, posrednike, digitalne platforme i krajnje kupce.
Što je SERP?
Search Engine Result Page — stranica s rezultatima pretraživanja; ona je rezultat algoritma tražilice, a ne web preglednika.
Čemu služi Google Analytics?
Generira detaljne statistike o prometu web stranice i izvorima prometa te mjeri konverzije i prodaju — otkriva odakle dolaze posjetitelji te što klikaju i čitaju.
